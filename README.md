# Smart Student Management System

## About the Project

This project is developed using Python to demonstrate how academic data can be efficiently organized and managed using Python programming concepts and collections. The system helps educational institutions maintain student records, track academic performance, and manage student information in a structured manner.

## Objectives

- Store and manage student information efficiently.
- Add, search, update, and delete student records.
- Manage academic details such as courses, marks, and grades.
- Calculate individual and overall academic performance.
- Generate student academic reports.
- Search students by department or course.
- Demonstrate the use of Python collections such as lists, tuples, sets, and dictionaries.

## Technologies Used

- Python 3

- VS Code

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
py application/student_record_management.py
```

or

```bash
python application/student_record_management.py
```

## Expected Output

The system allows users to:

- Add new student records
- View all student details
- Search records by Student ID
- Update student information
- Delete student records
- Calculate marks, grades, and academic performance
- Generate summary reports

## Important Note

Student and academic records are stored in memory while the application is running. Data will be reset when the program is restarted unless permanent database storage is implemented.
